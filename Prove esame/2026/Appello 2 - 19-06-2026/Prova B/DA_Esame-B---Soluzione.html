💥 Risposta:

Il modello di regressione lineare semplice stimato è:

Happiness_Score = 8.072 - 0.0222 * Air_Quality_Index

Interpretazione dei coefficienti:
- Intercetta (8.072): valore atteso di Happiness_Score quando Air_Quality_Index è 0 (non interpretabile in termini reali).
- Pendenza (-0.0222): per ogni unità in più di Air_Quality_Index, il Happiness_Score diminuisce in media di 0.0222 (p-value < 0.001). L’effetto è statisticamente significativo.

Bontà del modello:
- R² = 0.6965: il modello spiega circa il 69.7% della variabilità di Happiness_Score.
- R² aggiustato = 0.6938
- p-value del modello: < 2.2e-16 (modello complessivamente significativo)

La relazione è negativa e forte: all’aumentare dell’inquinamento (Air_Quality_Index più alto), la felicità tende a diminuire.

# Funzione richiesta
funzione <- function(x, y) 
{
  # Punto a: Controllo dei tipi
  if (is.numeric(x) && is.character(y)) 
  {
    print("OK: il vettore x è di tipo numeric, mentre y è di tipo character")
  } else {
    stop("Errore: x deve essere numeric e y deve essere character")
  }
  
  # Punto b: Calcolo del 25-esimo percentile
  p25 <- quantile(x, probs = 0.25, na.rm = TRUE)
  
  # Creazione della variabile z: 1 se x <= al 25-esimo percentile, 0 altrimenti
  z <- ifelse(x <= p25, 1, 0)
  
  # Punto c: Creazione del data frame con x e y
  df <- data.frame(x = x, y = y)
  
  # Selezione delle righe con z == 1
  df_selezionato <- df[z == 1, ]
  
  return(df_selezionato)
}
